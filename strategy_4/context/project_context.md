# Project Context: CS440 Repository

This repository includes the AIMA Python codebase and the Strategy 1 and Strategy 4 context-engineering demonstrations.

Relevant AIMA vacuum-related files include:
- `aima-python/gui/vacuum_agent.py`: two-location vacuum environment GUI.
- `aima-python/gui/xy_vacuum_environment.py`: two-dimensional vacuum environment GUI.
- `aima-python/gui/grid_mdp.py`: grid-based Markov decision process GUI.
- `aima-python/aima/mdp.py`: reusable MDP and GridMDP algorithms.

These are existing AIMA examples; this repository does not currently include a separate `q_learning.py` file. Strategy 4 should review the actual relevant files supplied to it and should not assume a Q-learning assignment.
